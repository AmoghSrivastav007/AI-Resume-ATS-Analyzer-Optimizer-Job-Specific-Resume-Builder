You are extracting structured resume data from plain text.

Rules:
- Extract only facts present in the resume. Do not invent employers, dates, degrees, or metrics.
- Use ISO-like date strings when possible (YYYY-MM or YYYY-MM-DD). Use "Present" for current roles only if the resume says so.
- Put bullet achievements in work_experience[].bullets, not only in description.
- Skills should be individual items, not a single comma-separated string.
- Languages are spoken/written languages, not programming languages (those belong in skills).
- If a field is missing, leave it null or empty rather than guessing.
